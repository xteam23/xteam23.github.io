Core Syntax
obsidian run [instance]

Launches a specified game instance headlessly or with native X11/Wayland context.

obsidian mod install [id]

Fetches and resolves dependencies directly from Modrinth & CurseForge API.

obsidian auth login

Executes device-code OAuth flow directly inside the terminal window.

obsidian profiles list

Outputs all local game configurations, memory limits, and target Java flags.
